# Clawd 手動チェック（約30秒）

Clawd があなたの作業中のウィンドウを奪わないことを、実際の操作で確かめるチェックです。Mac が空いているとき（重い作業をしていないとき）にお願いします。

## 始め方

ターミナルで次を実行します。

```
cd ~/Projects/clawd-pet && scripts/attended-check.sh --real --menu
```

## 手順（この順番で）

1. ターミナルを一番前に置いたままにします。チェックが終わるまで、ターミナルはクリックしません（クリックすると「メニューの外をクリックした」扱いになります）。
2. Clawd を右クリックします。メニューが開き、ターミナルに4文字の英単語が表示されます。
3. マウスをメニューの中の項目2つの上に順に乗せ、そのままメニューの上に置いておきます。
4. 表示された4文字の単語をキーボードで打って、Return を押します。ターミナルが前にあるので、クリックせずにそのまま打てます。
5. メニューの「Walk」の行で、すでに選ばれている（色が付いている）ボタンをクリックします（設定は変わりません）。メニューが閉じます。
6. もう一度 Clawd を右クリックします。
7. デスクトップか、ターミナル以外のアプリのウィンドウを1回だけクリックします（Clawd とメニューから離れた場所、ダブルクリックはしない）。そのアプリが前に出て、数秒後にチェックが終わります。

これ以外のクリック（メニューが出ていないときのターミナル、メニューバー、2回目のクリック）をすると、結果は NOT RUN になります。その場合はもう一度最初からやれば大丈夫です。

## 終わったら

最後に表示される `PASS` / `FAIL` / `NOT RUN` の行を、そのまま教えてください（コピーでも写真でも構いません）。
